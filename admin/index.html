第一次使用

这个页面把照片直接提交到 GitHub 仓库，Cloudflare 收到后约 1 分钟自动上线。

1. 生成一个令牌

  1. 打开 GitHub 细粒度令牌页面
  2. Token name 随便填，Expiration 选 90 days
  3. Repository access 选 Only select repositories → 勾 sux6098-pixel/wthdwt-home
  4. Permissions → Repository permissions → 找到 Contents，改成 Read and write
  5. 点 Generate token，复制那串 github_pat_...

令牌只存在这台手机的浏览器里，不会上传到任何服务器，我也看不到。丢了就在 GitHub 删掉重新生成。两人各自生成一个也可以，共用一个也行。
